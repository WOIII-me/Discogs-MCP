# Held-out labelling worksheet

One block per release. For each claim write exactly one of `stated`, `denied`, `not_stated`, `contradictory`,
or leave it blank to keep that claim unlabelled (use blanks for genuinely borderline cases and say why in `notes:`).
Do not look at any model output while labelling. Conventions: see scripts/eval/jev/README.md.

Claim definitions:
- **analogSource** — this pressing was mastered or cut from an analog source (original master tapes, AAA, all-analog)
- **digitalSource** — this pressing was mastered or cut from a digital source or file
- **dmm** — this pressing was cut using Direct Metal Mastering (DMM)
- **pressingPlant** — the text names the plant or facility where this pressing was manufactured
- **qcComplaints** — the text reports quality-control problems with this pressing (noise, warps, off-centre, non-fill, defects)
- **nonConsumer** — this item is not a standard retail copy (test pressing, promo, white label, acetate, jukebox, not for sale)
- **firstPressing** — this is a first pressing / original pressing of the album
